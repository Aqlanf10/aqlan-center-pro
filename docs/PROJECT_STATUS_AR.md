# القرارات الملزمة وحالة التنفيذ

آخر تحديث: 2026-10-05 — توقيت آسيا/عدن.

## قرارات أحدث من نسخة الخطة الأصلية

- العربية اللغة الأساسية والافتراضية؛ الإنجليزية ثانية مع RTL/LTR والترجمة لكل الواجهات والتقارير والقوالب والبوابات والتطبيقات. بيانات المريض المكتوبة لا تُترجم تلقائيًا.
- يسمح بالعمل المتوازي وبدمج الفروع المكتملة بعد المراجعة ونجاح الاختبارات المتعلقة بها على الرأس نفسه.
- سعر الصرف البرمجي = وحدات عملة السداد لكل وحدة من عملة الدين. مثال اختباري: 14000 YER ÷ 140 YER/SAR = 100 SAR. أي نص في الخطة يستخدم الاتجاه العكسي يُقرأ كشرح عام؛ حقول التنفيذ تسمي الاتجاه صراحة وفق هذا القرار. لا يوجد سعر صرف حالي مفترض.

## حالة يمكن التحقق منها

| العنصر | الحالة |
|---|---|
| المستودع الخاص Aqlanf10/aqlan-center-pro | أنشئ |
| الخطة الشاملة HTML (22 قسمًا) وتعليمات المهندسين | موثقة في المستودع |
| نواة الأموال والافتتاحيات | كود في PR #1؛ 10 اختبارات محلية ناجحة؛ لم يدمج بعد |
| مخطط PostgreSQL ومعاملات الحالات الجديدة والقديمة | قيد التطوير؛ اختبارات PGlite أولية ناجحة، تنتظر التزامن على PostgreSQL والخادم |
| المصادقة والخادم والواجهة العربية/الإنجليزية | قيد التطوير والمراجعة؛ ليست إصدارًا جاهزًا |
| Railway | لم ينشر هذا المشروع بعد |
| استيراد فعلي من أرشيف المركز | لم ينفذ؛ لا بيانات مرضى في بيئة التطوير |
| ملفات التخصصات المتقدمة والرسائل والبوابات والتطبيقات | متطلبات ملزمة في الخطة، لم تكتمل |
| اختبار الاستعادة والتشغيل السريري | لم يجر؛ يمنع إعلان الجاهزية |

## كيفية قراءة الخطة

MASTER_PLAN_AR.html نسخة كاملة محفوظة من وثيقة التخطيط المعتمدة إصدار 1.6، تشمل الهوية والصور المرجعية وجميع الأقسام. الفقرات التي تصف حالة المستودعات أو التنفيذ داخلها تعكس وقت إعدادها. هذا الملف ومصفوفة المتطلبات يُحدّثان لتسجيل الواقع؛ لا يُحذف نطاق من الخطة بصمت، ولا يصبح وعد التخطيط ادعاءً بأنه منفذ.

المحاسبة الحالية نواة دفتر تشغيلي؛ ليست منظومة مالية أو ضريبية مكتملة. خدمات المعامل والموردين والعمولات والصناديق والإقفال والتقارير تحتاج تنفيذًا واختبارات مستقلة مترابطة قبل التشغيل.
