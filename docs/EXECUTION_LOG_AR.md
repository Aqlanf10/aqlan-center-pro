## العيوب التي كشفها الفحص

1. `jsonb_agg` لسطور القيد يحول المبالغ إلى JSON numbers؛ `9999999999999999.99` يفقد دقته لدى العميل. الإصلاح: نصوص عشرية قبل بناء JSON واختبار عبر HTTP.
2. اعتماد افتتاحي قديم لا يرتبط بالنسخة التي شاهدها المعتمد: تغيير 1000/400 إلى 10000/0 بين العرض والاعتماد يرحل 10000 بدل 600. الإصلاح: إصدار للخطة و`expectedVersion` للمراجعة والتفعيل؛ رفض النسخة المتقادمة دون أثر جزئي.
3. إعادة `plan.create` بالمفتاح السابق تفحص الصلاحية السريرية وتتجاوز صلاحيات المبلغ الإضافية بعد سحبها. الإصلاح: إعادة جميع الصلاحيات المطلوبة قبل إعادة النتيجة المحفوظة.
4. فحص الجاهزية كان يقبل المخطط 3 قبل حد التشغيل المقيد. يجب أن يرفض مخططًا أقدم من هجرات الإصدار الحالي.
5. تبديل اللغة كان يفقد حقول الدخول والبحث؛ تصحيح الواجهة مع اختبار متصفح، دون ترجمة بيانات المريض.
6. قراءة الرصيد والقيود بطلبَي SQL منفصلين يمكن أن تجمع رصيدًا سابقًا مع دفعة أحدث في الرد نفسه. جُمعت القراءتان في لقطة SQL واحدة واختُبر وصول قبض بين القراءة وتجميع الرد.
7. عميل PostgreSQL يحول DATE إلى وقت محلي ثم UTC؛ ظهر تاريخ القطع السابق بيوم في اختبار المتصفح الفعلي. حقول التواريخ التقويمية تخرج الآن كنصوص SQL صريحة؛ اختبار المتصفح في CI يستخدم PostgreSQL 17 وتوقيت Asia/Aden.
8. اختلاف نهايات السطور بين Windows وLinux يغير بصمة ملف الهجرة رغم ثبات SQL. `.gitattributes` يثبت LF لملفات db؛ تبقى مقارنة checksum صارمة. أعيد الاختبار من أرشيف Git الفعلي على قاعدة جديدة دون تعديل أي بصمة مسجلة.
