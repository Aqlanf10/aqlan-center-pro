## G-ALL: تعريف الإنجاز لكل متطلب

لا يسمى المتطلب مكتملًا إلا بتوفر: واجهة مناسبة للدور **بالعربية افتراضيًا والإنجليزية بديلًا**، API وعقد أخطاء، تخزين وهجرات، تحقق مراجع وصلاحيات خادمية، تدقيق، أثر مالي صريح أو بيان عدم وجوده، فشل واستئناف ومنع تكرار وتزامن عند اللزوم، واختبار قبول مرتبط بـID. اختبار الوحدة وحده لا يثبت الرحلة. القالب العام أو حقل تخصص لا يثبت اكتمال الملف التخصصي. لا أزرار معطلة أو بيانات تجريبية توصف بوظائف حية.

تسجل نتيجة كل حالة في دليل إصدار: `ID، متطلبات، commit، بيئة، fixture/ساعة، أمر الفحص، نتيجة، أثر DB/دفتر، دليل واجهة، مراجع، قيود`. نجاح النسخة الماضية لا يغطي تغييرًا لاحقًا. لم تُنشأ نتائج تلقائية في هذا الملف.

## أدلة التغطية وحدودها الحالية

ملف `tests/domain.test.mjs` يثبت الحساب الدقيق البسيط والتحويل ومقترح افتتاحي وحالات مجهول/متنازع/دائن/مسدد ومفتاح المصدر. يضاف إليه الدليل CI أعلاه لجزء من DB والمعاملات ومنع التكرار والتحصيل الزائد، والتحقق الأولي من صلاحيات أدوار التشغيل. لا يثبت هذا وحده كل AC-01/02/05/09 أو قبول التخصصات أو الاستيراد الكامل.

النواة السريرية (5 اختبارات) ومعاينة الاستيراد (13 اختبارًا) محليتان منفصلتان غير مدمجتين عند تسجيل الدليل؛ وجودهما لا يحقق نموذج تقويم أو معالج استيراد عاملًا. المسار LEGACY-07 (مسودة مجهول→مراجعة→تفعيل) قيد العمل، وهو مختلف عن LEGACY-04 لتصحيح افتتاحي مُرحّل؛ الأخير لم يُنفذ. كود بوابة الاستعادة جديد خارج CI، فلا يُعلن RESTORE-A01 ناجحًا. لا دليل نشر إنتاج أو استعادة DB مع كل المرفقات حتى الآن.

المتبقي قبل تشغيل حقيقي: تعميم مصادقة وعزل على جميع المسارات، دفتر وسياسات معتمدة وتصحيح/عكس وفترات، رحلة جديد وقديم كاملة، الهجرات/استعادة DB والمرفقات، وترجمة عربية/إنجليزية مكتملة ودليل واجهة. قبول أساس جزئي لا يسقط هذه البوابات. جميع حالات القبول أعلاه تبقى مطلوبة؛ نقل حالة إلى ناجح يحتاج سجل دليل مرتبط بالنسخة، لا مجرد وجود وصفها في هذا الملف.
