## المبادئ الملزمة

- **العربية اللغة الأساسية والافتراضية**؛ الإنجليزية لغة ثانية مع تبديل RTL/LTR. واجهة البرنامج ورسائل الأخطاء والتقارير والقوالب والبوابات والتطبيقات تدعم اللغتين. محتوى المرضى المدخل يدويًا يبقى بلغته الأصلية.
- ملف مريض موحد للحالات الجديدة والقديمة، مرتبط بالتخصصات والخطط والزيارات والإجراءات والمواعيد والحسابات.
- فواتير واتفاقات بأي من YER / SAR / USD، وسداد بعملة أخرى مع حفظ السعر واتجاه التحويل والمبلغين؛ لا جمع للعملات كأنها عملة واحدة.
- الحالة السابقة تسجل الاتفاق والمدفوع والعمل المنجز والمتبقي مع مصدر الإثبات؛ لا إيصال وهمي ولا إعادة احتساب المال القديم كدخل اليوم.
- صلاحيات خادمية قابلة للضبط وعزل فروع وسجل تدقيق، دون إعدادات تسمح بإلغاء سلامة البيانات.
- الموقع والبوابات والتطبيقات وشاشة الصالة والرسائل تستند إلى خدمات وبيانات مشتركة.
- الاستضافة المستهدفة: **Railway** للواجهة والخلفية وقاعدة PostgreSQL.

## حالة التنفيذ والتسليم

دُمج كود الأساس المتكامل في [PR #1](https://github.com/Aqlanf10/aqlan-center-pro/pull/1) بعد مراجعة ونجاح [CI النهائي](https://github.com/Aqlanf10/aqlan-center-pro/actions/runs/37243541414) على `d5d48f1`: **70 اختبارًا ناجحًا**، ورحلات Chromium على PostgreSQL 17 بالعربية والإنجليزية، والتزامن والاستعادة وبناء صورتي التشغيل والهجرات. أُنشئت قاعدة Railway في staging مستقل؛ الواجهة لم تُنشر بعد. المتابعة الحالية تضيف تحقق شهادة اتصال قاعدة البيانات وإعدادات النشر المعتمدة للخدمات الجديدة.

التفاصيل الدقيقة وما يجب تنفيذه بعد ذلك في [تسليم Codex](docs/CODEX_HANDOFF_AR.md). **البرنامج ليس مكتملًا أو جاهزًا للتشغيل السريري بعد.**

تابع [سجل التنفيذ الجديد](docs/EXECUTION_LOG_AR.md) و[الحالة الحالية](docs/PROJECT_STATUS_AR.md) و[أدلة Railway](docs/RAILWAY_STAGING.md)؛ أرقام التسليم القديم لا تستبدل الأدلة الأحدث.
